What the audit does

UX/UI/AX Audit - Vision AI analyses the screenshot against Nielsen's 10 Usability Heuristics. Multiple models vote on severity; scores are weighted by reliability. HTML source is parsed in-browser for structural WCAG 2.1 issues (no API call).

Pattern Research - Claude identifies UI patterns in the screenshot and searches how reference products (Amazon, Galaxus, GOV.UK etc.) solve the same design challenge - with research citations.

Test Analysis - Claude cross-references your usability test feedback with the screenshot, explains root causes, and shows how reference products solve each issue.

Quality Mode - Groq checks specificity, Apertus checks relevance, GitHub Models checks fixability. Claude synthesises all feedback and revises flagged findings.

Interpreting the tabs

Annotated Screenshot - numbered pins mark findings. Pin colour = severity (red = 4, orange = 3, yellow = 2, grey = 1). Click pin or sidebar item to select.

Visual (AI) findings require manual verification. Structural checks cover WCAG Level A only.

Priority Matrix - Impact vs. Effort plot. Drag the Effort slider per finding to override the estimate. Quadrants: Quick wins / Major projects / Fill-ins / Don't bother.

Jira Tickets - User stories generated per finding with Goals, Logic and testable Acceptance Criteria. Copy as wiki markup or JSON.

QA Test Cases - Technical test cases with preconditions, steps and expected results for the testing engineer to verify fixes.

Recommended workflow
  1. Choose mode - UX/UI/AX Audit, Pattern Research or Test Analysis
  2. Prepare input - screenshot + optional CSS / HTML / feedback
  3. Configure - region, industry, product context; enable Quality Mode for higher accuracy
  4. Review - filter >= 80% confidence; challenge false positives; add Jira comments
  5. Export - PDF (Full / UX/UI / AX), Confluence wiki markup, or copy Jira tickets
